# Contributing

Thanks for helping improve **GDM K4811 App suite**.

## How to contribute

1. Open an issue describing the bug or idea (optional but welcome).
2. Fork the repo and create a branch from `main`.
3. Make your changes. Keep the UI simple and safe for driving.
4. Test on a real NWD head unit when you can.
5. Open a pull request with a short explanation of what changed and why.

## Guidelines

- Follow the existing code style (plain Java, Android Views, no new libraries unless discussed first).
- Prefer small, focused pull requests.
- Do not change audio or radio behavior unless that is the point of the change.
- Be respectful — see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

# Contribuindo

Obrigado por ajudar a melhorar o **GDM K4811 App suite**.

## Como contribuir

1. Abra uma issue descrevendo o bug ou a ideia (opcional, mas bem-vindo).
2. Faça um fork e crie uma branch a partir de `main`.
3. Faça suas alterações. Mantenha a interface simples e segura para dirigir.
4. Teste numa central NWD real quando puder.
5. Abra um pull request com uma explicação curta do que mudou e por quê.

## Orientações

- Siga o estilo do código atual (Java puro, Android Views, sem bibliotecas novas sem combinar antes).
- Prefira pull requests pequenos e objetivos.
- Não altere o comportamento de áudio ou rádio a menos que esse seja o objetivo da mudança.
- Seja respeitoso — veja o [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
