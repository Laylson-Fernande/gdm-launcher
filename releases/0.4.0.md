## 🇧🇷 Português

### Novidades
- 6 novos idiomas em **Configurações → Idioma**: **Español**, **Français**, **Русский** (russo), **日本語** (japonês), **中文** (mandarim, chinês simplificado) e **हिन्दी** (híndi)
- Ao todo são 8 idiomas, contando **Português** e **English** (padrão)
- Cada idioma aparece no seletor com a bandeira de referência e o nome escrito no próprio idioma
- A data da tela inicial segue as regras de cada idioma (meses em minúscula em espanhol, francês e russo; "10月" em chinês)

### Instalação
Baixe o APK, instale na central e, se pedido, escolha **Garagem** como launcher padrão.

## 🇺🇸 English

### What's new
- 6 new languages in **Settings → Language**: **Español** (Spanish), **Français** (French), **Русский** (Russian), **日本語** (Japanese), **中文** (Mandarin, Simplified Chinese) and **हिन्दी** (Hindi)
- 8 languages in total, counting **Português** and **English** (default)
- Each language is shown in the picker with a reference flag and its name written in that language
- The home screen date follows each language's rules (lowercase months in Spanish, French and Russian; "10月" in Chinese)

### Install
Download the APK, install it on the head unit and, if prompted, set **Garagem** as the default launcher.
