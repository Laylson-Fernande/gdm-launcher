## 🇧🇷 Português

### Novidades
- Novo ícone **Z-Link** no dock, para abrir o CarPlay / Android Auto da central (app `com.zjinnova.zlink`)
  - Ative em **Configurações → Customizar → Customizar dock → Z-Link** (conta no limite de 5 ícones; vem desligado)
  - Em **Nome do Z-Link no dock**, escolha como ele aparece: **Z-Link**, **CarPlay** ou **Auto**. O ícone muda junto com o nome
  - Só aparece em centrais com o Z-Link instalado

### Instalação
Baixe o APK, instale na central e, se pedido, escolha **GDM Launcher** como launcher padrão.

## 🇺🇸 English

### What's new
- New **Z-Link** dock icon, to open the head unit's CarPlay / Android Auto (app `com.zjinnova.zlink`)
  - Turn it on in **Settings → Customize → Customize dock → Z-Link** (it counts toward the 5-icon limit; off by default)
  - In **Z-Link name in the dock**, choose how it shows: **Z-Link**, **CarPlay** or **Auto**. The icon changes with the name
  - Only shown on units with Z-Link installed

### Install
Download the APK, install it on the head unit and, if prompted, set **GDM Launcher** as the default launcher.
