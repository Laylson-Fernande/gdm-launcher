## 🇧🇷 Português

### Novidades
- Cor do tema em **Configurações → Aparência → Cor do tema**, com 14 opções:
  - **Cinza**, **azul**, **violeta**, **vermelho**, **laranja**, **amarelo** e **verde**
  - Linha de cima: a cor como destaque sobre fundo preto (**cinza sobre preto** continua como padrão)
  - Linha de baixo: a mesma cor com o fundo em um tom escuro dela
- Todas as cores do tema são geradas a partir da cor escolhida, mantendo o modo escuro e a leitura dos textos
- Cores de erro, aviso e sucesso não mudam com o tema

### Instalação
Baixe o APK, instale na central e, se pedido, escolha **Garagem** como launcher padrão.

## 🇺🇸 English

### What's new
- Theme color in **Settings → Appearance → Theme color**, with 14 options:
  - **Gray**, **blue**, **violet**, **red**, **orange**, **yellow** and **green**
  - Top row: the color as the accent on a black background (**gray on black** remains the default)
  - Bottom row: the same color with a background in a dark shade of it
- Every theme color is derived from the chosen color, keeping dark mode and readable text
- Error, warning and success colors don't change with the theme

### Install
Download the APK, install it on the head unit and, if prompted, set **Garagem** as the default launcher.
