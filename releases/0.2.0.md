## 🇧🇷 Português

### Novidades
- Seletor de fonte em **Ajustes → Aparência → Fonte**
- Novas fontes: **Montserrat**, **Rajdhani**, **Outfit**, **Inter** e **Public Sans** (**Exo 2** continua como padrão)
- Textos longos ou fontes mais largas se ajustam melhor na home (auto-fit)

### Instalação
Baixe o APK, instale na central e, se pedido, escolha **Garagem** como launcher padrão.

---

## 🇺🇸 English

### What's new
- Font picker in **Settings → Appearance → Font**
- New fonts: **Montserrat**, **Rajdhani**, **Outfit**, **Inter** and **Public Sans** (**Exo 2** remains the default)
- Long labels and wider fonts fit better on the home screen (auto-fit)

### Install
Download the APK, install it on the head unit and, if prompted, set **Garagem** as the default launcher.
