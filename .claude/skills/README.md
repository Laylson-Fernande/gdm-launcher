# Skills do projeto

Skills de terceiros copiadas para cá (o equivalente a `npx skills add`), carregadas pelo Claude Code ao abrir o repositório. Todas com licença MIT; o texto da licença está no repositório de origem.

| Skill | Origem (commit) | Para quê |
|---|---|---|
| `find-skills` | [vercel-labs/skills](https://github.com/vercel-labs/skills) (`92a9a34`) | achar e instalar outras skills quando aparecer uma tarefa nova |
| `using-superpowers` | [obra/superpowers](https://github.com/obra/superpowers) (`2ce8aa1`) | disciplina de usar as skills antes de agir; cita outras skills do Superpowers (brainstorming, writing-plans…) que não estão instaladas aqui |
| `limrun-android-emulator` | [limrun-inc/skills](https://github.com/limrun-inc/skills) (`ad9559c`) | instalar e testar o APK num emulador Android na nuvem (Limrun); precisa do CLI `lim` (`npm install --global lim`) e de `LIM_API_KEY` |

Para atualizar: copie de novo a pasta da skill do repositório de origem e troque o commit acima.
